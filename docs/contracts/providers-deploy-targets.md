# Deploy Target Contract

Domain: `kind = "deploy"` provider entries — the hosts or platforms a
delivery pipeline promotes an accepted change to.

No content has moved into this document yet: deploy-target provider entries
share the identifier, authentication, and untrusted-output invariants in
[`providers.md`](providers.md), and their typed extensions are specified by
the PRD that introduces each deploy target.

See [`providers.md`](providers.md) for the invariants shared across all
provider domains.
