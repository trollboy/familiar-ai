# Billing Source Contract

Domain: `kind = "billing"` provider entries — authoritative collectors an
operator configures so Familiar can reconcile cost observations against a
provider's own billing records (PRD-052, PRD-054).

No content has moved into this document yet: billing-source provider entries
share the identifier, authentication, and untrusted-output invariants in
[`providers.md`](providers.md), and their typed extensions are specified by
the PRD that introduces each billing source.

See [`providers.md`](providers.md) for the invariants shared across all
provider domains.
