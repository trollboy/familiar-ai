# PRD-077: Autonomous Wave Delivery

## Objective

Close FAM-BUG-019/022: two waves delivered thirteen PRDs and Familiar
autonomously integrated zero — the operator performed the merge queue,
review arbitration, verification, and completion for every one. This PRD
makes the cascade impossible: dependents consume integration (not
narration), incomplete implementations terminalize instead of passing
through, repeated deterministic failures stop the session with an
executable recovery plan, remediation cannot orphan its own checkpoint
(FAM-BUG-018/021), and `resume all` finishes preserved candidates rather
than delegating Git surgery to the operator. Its final acceptance
criterion is FAM-BUG-019's own closure condition.

## Scope

Integration-contained dependency admission in drive selection; the
implementation_incomplete terminal class; the deterministic-failure
circuit breaker with recovery-plan emission; atomic checkpoint
advancement on remediation; resume-to-completion including re-binding
operator-committed candidates; regressions for each in a dedicated test
file. Out of scope: preflight contract (PRD-078), reviewer routing
(PRD-079), scope policy (PRD-080).
