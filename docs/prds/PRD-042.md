# PRD-042: Repository Risk Vocabulary


## Objective

Give `risk_classes` a closed, repository-scoped vocabulary so a declared risk
class is a validated contract value, not free text.

## Scope

- Add a `risk_vocabulary` list to repository-scoped configuration.
- Document the vocabulary requirement in the Structured PRD Contract v1.
- Reject unknown risk classes in structured PRD parsing and `metadata-check`,
  naming the path and the offending class.
- Change no routing, review, or execution behavior in this PRD.
