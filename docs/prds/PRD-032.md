# PRD-032: Model Probation and Empirical Routing

**Status:** Ready for implementation
**Date:** 2026-08-26
**Depends on:** PRD-028, PRD-029, PRD-031, PRD-039, PRD-041, PRD-044, PRD-045

## Objective

Let new workers earn routing trust on bounded low-risk work using persisted
verification, independent-review, cost, latency, and acceptance evidence.

## Scope

- Define probation warrants and incumbent-review requirements.
- Compute review-pass rate, remediation rate, cost per accepted PRD, cache
  effectiveness, and failure rate by worker/model/version.
- Promote or demote only through deterministic operator policy.
- Include subscription headroom as declared availability, never inferred billing.
- Preserve raw observations and policy versions behind every score.

## Acceptance Criteria

1. A new model cannot receive non-probation work before meeting policy.
2. Failed verification or review affects its score without erasing evidence.
3. Promotion/demotion is reproducible from persisted rows and policy.
4. Unknown cost or identity cannot be ranked as cheap or trusted.
5. An operator can pin, quarantine, or retire a worker explicitly.
