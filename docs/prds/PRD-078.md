# PRD-078: Preflight and Verification Contract Integrity

## Objective

Close FAM-BUG-011/015/020/024: preflight silently converted configured
verification into a lossy command (dropping environment and timeout,
discarding output), probed credentials for workers the session never
routes to, repeated identical expensive probes per stage, and ran for
five to ten silent minutes before returning only an exit code. Preflight
becomes a faithful, observable, minimal execution of exactly what
configuration declares.

## Scope

Exact-spec verification execution with bounded redacted output retention;
routed-worker-scoped credential probes; per-session probe deduplication;
flushed heartbeats; environment-denial classification; regressions in a
dedicated test file. Out of scope: reviewer capability probes (PRD-079),
delivery semantics.
