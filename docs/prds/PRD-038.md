# PRD-038: Multi-Repository Have-At-It Acceptance

**Status:** Ready for implementation
**Date:** 2026-08-26
**Depends on:** PRD-019, PRD-020, PRD-032, PRD-033, PRD-034, PRD-036, PRD-037, PRD-039

## Objective

Establish the repository-agnostic product acceptance proof: design documents
in, one approved decomposition, unattended bounded execution, and an exact
morning report across materially different repositories.

## Acceptance Criteria

1. At least two fixture repositories with different languages, layouts, and
   dependency identities complete onboarding without code changes.
2. The planner drafts a valid dependency-ordered batch and records one human
   batch approval plus its warrant.
3. Independent branches execute concurrently; dependencies and shared scopes
   serialize correctly.
4. Worker routing includes a cheap/local task and independent strong review.
5. Injected failures strand only affected work and survive supervisor restart.
6. Manual delivery stops at reviewed PR; explicit PoC mode self-approves only
   within its warrant; review-gated mode preserves separation evidence.
7. Reports state work, blockers, cost, cache behavior, human gates, and recovery.
8. Repeating the proof creates no duplicate claims, PRs, merges, or deployments.
