# PRD-081: Reachable Approval — the Decidable Pause

## Objective

Familiar retains rather than guesses on a scope decision, which is the
right design, and then hides the only command that continues the work.
The session report offers a stopped attempt exactly two continuations —
`backlog release`, which throws the work away, and `backlog complete`,
which bypasses every gate ([report.rs:563](../../../crates/familiar-ai-daemon/src/report.rs)).
`scope-decisions --approve` appears in one drive log line at the instant
of the pause and nowhere afterwards. The interactive picker in
`cli/scope_decisions.rs` is never reached from the pause, and when it is
reached it asks the operator to type a sha256. An operator who did not
write this code cannot approve anything without reading source. Retaining
is only half a design; this PRD builds the other half.

## Design

- **One pause, one command, every surface.** Whatever a human is looking
  at when a scope pause is discovered — the report, `stewardship gates`,
  `next`, `resume` — carries the same paste-runnable approve and reject
  commands for that specific attempt. Release and complete stop being the
  default advice for a decision they do not answer.
- **Ordinals, not hashes.** Hashes stay authoritative in storage and
  invisible in the interface. The picker enumerates pending decisions
  with enough context to decide (PRD, finding, proposed change) and takes
  a selection.
- **The pause reaches the operator.** The drive calls the decision
  surface when attended and prints the command when not, so the pause is
  never silent about its own remedy.

## Scope

Scope-pause rendering in every reporting surface; the interactive
decision surface (ordinal selection, decision context, actor capture);
the drive's pause invoking it; equivalence between interactive and flag
decisions; regressions in a dedicated test file.

Out of scope: scope classification policy (PRD-080), what constitutes a
scope finding (PRD-066), the wider command-surface redesign (PRD-088 —
this PRD fixes the pause regardless of where commands eventually live),
and unattended auto-approval, which is deliberately not built: the human
gate stays, it just becomes findable.

## Assumptions (recorded at specification time, 2026-09-04)

- The hash-bound decision contract from PRD-066 is correct and stays
  authoritative; only its presentation changes.
- An attended session can be detected by the same terminal check the
  existing picker uses; when detection is wrong, printing the command is
  the safe fallback and costs nothing.
