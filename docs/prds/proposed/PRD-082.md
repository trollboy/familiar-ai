# PRD-082: Operator Tools Are Shipped Commands

## Objective

Five tools that unstick real PRDs ship as `cargo run --example`:
`operator_rebind`, `operator_set_phase`, `operator_waive`,
`compute_width`, `probe_substance`. All five were used in a single
session to get work moving. A binary-release user has none of them and no
source tree to run them from, so the recovery path for the failures
Familiar most often hits exists only for people who build from source.
Tooling that durable operation depends on is product surface, not an
example.

## Design

- **Promote three, retire two.** Rebind, set-phase, and compute-width
  become supported commands under a single operator namespace. Waiving
  already has a CLI (`familiar-ai waive`, FAM-FRICTION-008); the example
  is now dead weight. `probe_substance` is a throwaway with this
  repository's path compiled into it — its one useful output becomes a
  stewardship query.
- **Authority travels with the command.** Every promoted command carries
  mandatory human actor and reason and keeps the FAM-BUG-048 guard that
  refuses to write durable state while a driver owns the claim. Promotion
  must not widen what an operator tool is allowed to do unobserved.
- **The examples directory stops being load-bearing.** A check enforces
  it, so the next stopgap cannot quietly become infrastructure.

## Scope

The operator command namespace and its three commands; the stewardship
substance query; deletion of the two retired examples; the examples
purity check; README operator documentation; regressions in a dedicated
test file.

Out of scope: new repair capabilities beyond what the five tools already
do, the scope-approval surface (PRD-081), and the overall command
hierarchy (PRD-088 — this PRD ships the commands; that one decides where
they finally sit).

## Assumptions (recorded at specification time, 2026-09-04)

- The three promoted tools are correct as written; promotion is a
  packaging and authority change, not a reimplementation.
- Operator repair remains a supported, audited activity rather than
  something to design away — PRD-083 measures how often it is needed.
