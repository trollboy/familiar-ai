# PRD-083: Unattended Stall Taxonomy and Autonomy Measurement

## Objective

Familiar is an autopilot that currently needs an expert co-pilot in the
seat. The good runs of the last session all involved surgery: rebinding
candidate snapshots, resetting checkpoint phases, computing widths by
hand, demoting a gate that had been wrongly promoted. Remove the expert
and most of those runs stall. The product cannot see this about itself —
there is no record of which completions were assisted, no closed
vocabulary for what a stall was, and no number that would move if
autonomy improved or regressed.

Measurement first: name every way a run stops, attach exactly one
recovery command to each, record every human write inside a PRD's
lifetime, and report the fraction of PRDs that finished without one.

## Design

- **A closed stall vocabulary.** Every pause or terminal classifies into
  a named class. A class without a recovery command is a defect in the
  taxonomy, caught by an invariant check rather than by an operator
  discovering there is nothing to run.
- **Interventions are durable, not remembered.** A human-actor write
  inside a PRD's admission-to-completion window is an intervention row
  carrying its command. This is what makes "it worked" and "it worked
  because I fixed it" different rows.
- **Autonomy is a reported number.** Per session and per repository:
  unattended completions, assisted completions, stalls, and the ranked
  intervention commands. A session below the configured floor reports as
  an autonomy failure — the metric is allowed to fail.

## Scope

The stall class vocabulary and its per-class recovery command; the
taxonomy invariant check; intervention recording; autonomy computation in
the session rollup and report; the stewardship autonomy query;
regressions in a dedicated test file.

Out of scope: reducing any particular stall — the recovery commands come
from PRD-082, the scope pause from PRD-081, and the circuit breaker and
recovery plans from PRD-077. This PRD names and counts; the reductions
are separately justified by what it counts.

## Assumptions (recorded at specification time, 2026-09-04)

- Human authority is already distinguishable in durable writes by the
  human: actor prefix that PRD-081 and PRD-082 both require.
- A recovery command per stall class is achievable today for every class
  worth naming; a class that genuinely has no remedy is recorded as an
  unrecoverable class with the reason, not omitted from the vocabulary.
