# PRD-080: Scope Authority Refinement

## Objective

Close FAM-BUG-014 and the wave-3/4 scope walls: declared manifest changes
retained as scope_ambiguous despite standing batch approval, required
test coverage judged as scope broadening, and every ambiguity terminating
an attempt instead of pausing it. Scope authority learns the difference
between an attack surface and the PRD's own declared contract, and
ambiguity becomes a decidable pause instead of a dead end.

## Scope

Declared-manifest decision minting at admission; declared-surface test
coverage allowance; pause-with-pending-decision semantics wired to 066's
hash-bound scope decisions; durable decision reporting; regressions in a
dedicated test file. Out of scope: the interactive decision command's UX
(exists since 066), review content policy.
