# PRD-027: Executable Under Any Profile

**Status:** Completed
**Date:** 2026-08-09
**Depends on:** PRD-008, PRD-013, PRD-017, PRD-025

## Objective

Make configured backlog profiles executable, not merely discoverable. Expected
Files is required only when configured as an authority source; early retained
failures preserve their cause; repository identities render in the repository's
convention; and driver ordering agrees with deterministic backlog ordering.

## Completion Evidence

- Configured scope can authorize a run without a missing Expected Files section.
- Present but malformed Expected Files remains fail-closed.
- Retained execution errors propagate into durable driver reasons.
- Suffixed numbered-slug identities and child-before-umbrella ordering are tested.
- Temporary numbered-slug fixtures reach fake-agent execution.

This recovered specification summarizes the completed PRD from
`origin/prd-023-location-is-truth`; its implementation is present on current
`main` through the profile, run-admission, reporting, and ordering changes.

## Acceptance Criteria

1. Non-authoritative Expected Files may be absent; authoritative or malformed
   contracts fail closed.
2. Every retained attempt has a durable reason.
3. Operator-facing identities follow the repository profile.
4. Deterministic selection and execution agree under every shipped profile.
