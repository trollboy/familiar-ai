# PRD-043: Risk-Aware Registry Route Rules


## Objective

Teach the worker registry to select on declared risk and expected scope size
through operator-authored rules, keeping selection pure and deterministic.

## Scope

- Add `rules` to `worker_registry.routing`: each rule matches on optional
  `risk_classes` (non-empty intersection) and optional `max_expected_files`,
  and names a target worker; first match wins, mirroring review tier rules.
- Extend `RouteRequest` with declared risk classes and expected file count.
- Apply the matched rule ahead of the existing cost-then-id tiebreak; keep
  the rejected-reasons audit trail.
- No drive or run wiring in this PRD; callers pass empty inputs unchanged.
