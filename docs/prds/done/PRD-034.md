# PRD-034: Portable Persistent Worker

**Status:** Completed
**Date:** 2026-08-26
**Depends on:** PRD-017, PRD-018

## Objective

Provide installable, observable, restart-safe workers on supported operating
systems without requiring operators to hand-author supervisor definitions.

## Scope

- Add install, uninstall, status, validate, and test commands for launchd and
  systemd.
- Preserve audited environment, logs, restart throttling, single-worker lock,
  bounded warrant, and durable recovery.
- Prove restart after process kill and machine/session restart on each platform.
- Prevent restart storms and duplicate morning reports.

## Acceptance Criteria

1. A harmless fixture proves first dispatch, failure restart, recovery, and one report.
2. Installation is idempotent and uninstallation preserves durable history.
3. Supervisor state and exact blockers are visible through Familiar.
4. Unsupported platforms fail before claiming work.
