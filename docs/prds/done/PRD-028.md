# PRD-028: Cost-Tiered Review

**Status:** Completed
**Date:** 2026-08-09
**Depends on:** PRD-008, PRD-013, PRD-026, PRD-039

## Objective

Select review depth deterministically from the measured change footprint so
trivial work does not pay frontier-review cost while unclassifiable or risky
work still receives full independent review.

## Scope

- Define `checks-only`, `standard`, and `full` review tiers.
- Select a tier from operator-authored rules over changed files, bytes, change
  kinds, and scope classes; models cannot select their own scrutiny.
- Treat missing, ambiguous, or unmatched evidence as `full`.
- Record tier, selecting rule, footprint, reviewer identity, and usage.
- Resolve tier policy per repository through PRD-026.

## Non-goals

- Skipping required deterministic verification.
- Allowing review tiers to widen file or deployment authority.
- Treating checks-only as acceptable for a repository that requires independent
  review for its assurance level.

## Acceptance Criteria

1. Unconfigured behavior remains full review.
2. Checks-only invokes no model and still requires every applicable check.
3. Standard uses the configured cheaper independent reviewer.
4. Unknown or high-risk footprints select full review.
5. Selection evidence is durable and appears in the morning report.
6. Invalid or self-contradictory rules fail before execution.
