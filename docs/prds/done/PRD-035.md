# PRD-035: Stewardship State API and MCP Surface

**Status:** Ready for implementation
**Date:** 2026-08-26
**Depends on:** PRD-017, PRD-018, PRD-033, PRD-039

## Objective

Expose Familiar's durable execution-era state through one read-first service
boundary used by CLI, MCP, dashboard, and future clients.

## Scope

- Query backlog graph, sessions, attempts, worktrees, review findings,
  verification, budgets, delivery, recovery events, and pending human gates.
- Add tightly scoped mutation tools only for existing audited human commands.
- Preserve pagination, repository isolation, redaction, and stable schemas.
- Make UI work consume this boundary rather than database internals.

## Acceptance Criteria

1. Every morning-report fact is queryable with matching provenance.
2. Cross-repository reads cannot leak state.
3. Secrets and unbounded model output never enter responses.
4. Mutations require the same explicit authority and audit as CLI operations.
5. MCP, CLI, and dashboard agree on shared fixture state.
