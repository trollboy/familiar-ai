# PRD-079: Capability-Probed Review Routing

## Objective

Close FAM-BUG-013/025: independent review was repeatedly routed to
workers that deterministically cannot perform it — an Ollama below the
required version, a model that reports it does not support tools — and
each time Familiar retried the impossible three times, then dressed the
configuration failure as human_review_required. Reviewer selection
becomes capability-proven: probed before selection, quarantined on
deterministic failure, rerouted while eligible reviewers remain, and
loudly stopped when none do.

## Scope

Capability/version probes persisted on worker specs; selection filtering;
session quarantine and reroute; typed no-reviewer stop; regressions in a
dedicated test file. Out of scope: probation scoring (PRD-032, landed),
preflight mechanics (PRD-078).
