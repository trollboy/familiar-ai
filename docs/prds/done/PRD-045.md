# PRD-045: Declared-Risk Review Tiering


## Objective

Compose declared PRD risk with observed diff risk in review tier selection so
a high-risk specification can never receive a reduced review.

## Scope

- Add `full_review_risk_classes` to review tier policy, validated against the
  repository risk vocabulary.
- Pass the PRD's declared risk classes into `select_review_tier`; any
  configured match forces `ReviewTier::Full`, mirroring the existing
  unknown-or-risky override and recording the class in the reason.
- Leave `ScopeFileClass` observation logic untouched.
