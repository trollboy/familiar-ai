# PRD-027: Executable Under Any Profile

**Status:** Ready for implementation
**Date:** 2026-08-09
**Depends on:** PRD-008, PRD-013, PRD-017, PRD-025
**Architectural direction:** Determinism Before Intelligence; Autonomy Fails Closed; Memory Must Be Durable
**Delivery boundary:** Independently mergeable correction of run admission, driver failure attribution, driver selection order, and profile-aware identity rendering

## Objective

Make a PRD executable under every shipped backlog profile, by requiring the Expected Files contract only where it is an authority source, recording *why* an attempt was retained even when it fails before review begins, and rendering a PRD's identity as its repository writes it everywhere an operator reads.

PRD-025 made a foreign backlog readable. PRD-026 made it verifiable. Neither made it executable.

## Motivation

The first real `drive` session against spectra attempted six PRDs, retained all six, spent nothing, and reported `reason=unrecorded` for every one. Four defects combined to produce that; the fourth was found only by the end-to-end test this PRD requires.

**The contract is demanded where it grants nothing.** `compute_review_preflight` parses the Expected Files contract unconditionally once review is enabled. It is gated on neither `allow_prd_expected_file_expansion` (`false` by default) nor `declaration_mode` (`expected_or_configured` by default, which states that configured `allowed_paths` is a sufficient authority source on its own). Under that configuration the contract contributes no authority whatever, yet its absence is fatal. The `numbered-slug` grammar treats a PRD body as opaque by design, so no PRD in such a repository can ever carry the section — making every one of them permanently unexecutable for a requirement the configuration explicitly waived.

**The reason is thrown away.** The driver matches `Err(_)` and records `trace.retained_reason`, which is populated only once the review flow is underway. An admission failure therefore records `None`, and the operator reads `reason=unrecorded`. The error explaining everything existed, in a variable, and was dropped. An unattended run that cannot say why it stopped is precisely the failure mode Familiar exists to prevent.

**Identity is rendered in the wrong convention.** The driver persists and prints `PrdId`'s canonical spelling (`PRD-177a`) rather than the repository's own (`PRD 0177a`), and because it is *persisted*, the morning report repeats it. PRD-025 promised an operator could grep their own backlog with Familiar's output; that promise is broken in the two places an overnight operator actually reads.

**The driver orders by path, not identity.** `select_next` sorts on `(number, path bytes)` rather than on the identity order PRD-025 defines. Sorting `0177-umbrella.md` against `0177a-child.md` by path bytes puts `-` (0x2D) before `a` (0x61), so the epic umbrella is selected *before* its children — executing a close-out document ahead of the work it closes, which is the precise outcome the epic-aware order exists to prevent. `BacklogManager::next` was corrected to sort by identity; the driver's separate implementation of the same decision was not, so `next` and `drive` disagree about what comes first.

The one thing that went right: it failed closed, before spawning an agent, at zero cost. Nothing was written, nothing needs unwinding.

## Semantics

- **The Expected Files contract is required only when it is an authority source.** It is mandatory when `allow_prd_expected_file_expansion` is `true` or `declaration_mode` is `expected_required`. Otherwise an absent section yields an empty contract and `allowed_paths` carries authority alone, exactly as the configuration declares. A section that is *present but malformed* remains fatal under every configuration — a contract offered is a contract honored, and silently ignoring a broken one would let a typo widen scope.
- **Every retained attempt records a reason.** The driver captures the error from a failed attempt and records it when `trace.retained_reason` is absent, so no attempt is ever stored as `unrecorded` because of an early failure. Reasons are bounded and single-line for report rendering; the full error remains on stderr.
- **Identity renders in the repository's convention wherever an operator reads it.** The driver persists and prints `DiscoveredPrd::display`, and the morning report renders what was persisted. Under `canonical` this is byte-identical to today in every observable.
- **Selection follows the identity order everywhere it is made.** The driver orders candidates by `PrdId`, agreeing with `BacklogManager::next` and with the store, so epic children are attempted strictly before their umbrella under every profile.
- **Authority is unchanged.** This PRD widens no scope, adds no capability, and relaxes no verification. It stops requiring a document the configuration already declared irrelevant, and it makes failures legible.

## Scope

This PRD includes:

1. Conditional Expected Files requirement in `compute_review_preflight`, gated on declared authority source, with malformed-when-present still fatal.
2. Error capture into the driver's retained reason for attempts that fail before review records one.
3. Profile-aware identity persistence and rendering in `drive`, carried through to the morning report.
4. Identity-order selection in the driver, agreeing with `next` and the store.
5. Focused tests over temporary repositories in both profiles, including an end-to-end `drive` under `numbered-slug` that reaches agent execution.

## Non-goals

This PRD does not:

- widen review scope, add scope classes, or change what `allowed_paths` authorizes;
- make a malformed Expected Files section tolerable under any configuration;
- change PRD-011 admission evidence, PRD-016/PRD-021 isolation, or the review cycle's structure;
- alter the `numbered-slug` grammar to parse PRD bodies for any purpose;
- backfill identity spelling on already-persisted driver attempts; or
- modify prior PRDs, architecture documents, ADRs, contracts, or philosophy.

## Behavior

Under a repository configured with `declaration_mode = "expected_or_configured"` and `allow_prd_expected_file_expansion = false`, a PRD with no `## Expected Files` section is admitted, and review authorizes exactly the configured `allowed_paths`. The same PRD under `declaration_mode = "expected_required"` is refused with a diagnostic naming the missing contract. A PRD carrying a malformed section is refused under both.

A `drive` attempt that fails at admission records the admission error as its retained reason, and the morning report renders it in place of `unrecorded`. A `numbered-slug` repository's attempts read `PRD 0177a`, matching the operator's own filenames.

## Acceptance Criteria

1. A PRD with no Expected Files section is admitted and executed when the configuration makes the contract non-authoritative, and review authorizes exactly the configured `allowed_paths`.
2. The same PRD is refused, by exact diagnostic, when `declaration_mode = "expected_required"` or `allow_prd_expected_file_expansion = true`.
3. A PRD whose Expected Files section is present but malformed is refused by exact diagnostic under every configuration, including the non-authoritative one.
4. An attempt failing before review begins records a non-empty retained reason derived from the actual error, and the morning report renders it rather than `unrecorded`.
5. A `drive` session under `numbered-slug` persists and prints identities in the repository's spelling, and the morning report renders that spelling, pinned byte-exact.
6. A `drive` over a backlog containing an epic umbrella and its children attempts every child strictly before the umbrella, agreeing with `next`.
7. Canonical repositories are byte-identical to today across the run, drive, review, and report suites, including identity rendering and existing Expected Files enforcement.
8. An end-to-end `drive` over a temporary `numbered-slug` repository with a fake agent reaches agent execution and completes an attempt, proving the path that produced six retentions now runs.
9. All tests use temporary repositories, databases, and fake agents; formatting, focused Clippy, focused tests, and the workspace suite pass, or demonstrably pre-existing failures are reported with exact evidence.
10. The change is confined to the expected files and is independently mergeable.

## Test Strategy

- Contract gating: a table over the four combinations of `allow_prd_expected_file_expansion` × `declaration_mode`, each asserting admitted-or-refused with its exact diagnostic, plus the malformed-section case refused in all four.
- Reason capture: an attempt forced to fail at admission, asserting the stored reason is non-empty, single-line, and names the cause; and the report rendering it.
- Identity: a `numbered-slug` drive fixture asserting persisted `prd_id` and both rendered lines, with a canonical fixture pinned byte-identical.
- End-to-end: a temporary `numbered-slug` repository driven with a fake agent through to a completed attempt.
- Regression: existing run, drive, review, report, and scope suites pass unchanged.

## Expected Files

The implementation is expected to modify or add only:

- `crates/familiar-ai-daemon/src/run.rs`
- `crates/familiar-ai-daemon/src/drive.rs`
- `crates/familiar-ai-daemon/tests/`

No new crate, third-party dependency, or migration is expected. Changes outside this list require explicit pull-request justification.

## Definition of Done

PRD-027 is done when a repository Familiar can read and verify is one it can also execute: the Expected Files contract is required exactly where the operator made it authoritative and nowhere else, every retained attempt states its own cause, identities read in the repository's own spelling, and an overnight `drive` over a non-canonical backlog reaches the agent instead of dying at admission in twenty-two milliseconds.
